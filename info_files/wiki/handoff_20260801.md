## Decisions
- Edge function chosen over Netlify's built-in Password Protection and `Basic-Auth` headers: both are Pro-plan only. Also chosen over an in-app passcode screen, which cannot hide the JS bundle.
- Unset `SITE_PASSWORD` is a deliberate no-op so `npm run dev` and unconfigured previews keep working.
- Gate CSS is inlined and there are no `excludedPath` entries, so new routes are covered with no edit.
- No brute-force throttling; a long passphrase carries the load. Marked with a `ponytail:` comment. Upgrade path is Netlify Blobs backed attempt counters.
- Netlify only. `vercel.json` still exists and has no equivalent middleware.
